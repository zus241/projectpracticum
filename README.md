# Project Defense

## Описание проекта

Учебный веб-проект
Это приложение для ведения личных записей: пользователь регистрируется, заходит под своим логином и работает со своими записями — создаёт, смотрит, редактирует и удаляет

Изначально делал в команде, но по итогу доделывал и оформлял всё сам.

Автор: СУШАНОВ МАКСИМ

## Что умеет проект

- Регистрация и вход пользователя
- Разделение на роли: гость, обычный пользователь, администратор
- Создание, просмотр, редактирование и удаление записей
- Проверка полей на валидность (длина логина, формат почты и т.д.)
- Связь между пользователем и его записями через внешний ключ
- Документация API в Swagger
- Тесты для эндпоинтов, которые работают с базой

## Стек

- Python 3.11
- FastAPI
- SQLAlchemy
- Alembic (миграции)
- Pydantic
- PostgreSQL (основная база), SQLite (для тестов)
- JWT для авторизации
- pytest для тестов
- HTML, CSS, JavaScript для фронта
- Git и GitHub
